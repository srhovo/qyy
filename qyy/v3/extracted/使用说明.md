# 见字如面 · 十九岁

给秦源悦的生日网页。打开 `index.html` 即可。

---

## 怎么用

**电脑**：双击 `index.html`，用 Chrome / Edge / Safari 打开。

**手机**：把整个 `birthday` 文件夹传到手机，用浏览器打开 `index.html`。
或者用微信发给她时，先把文件夹压缩成 zip 发过去，让她用手机浏览器打开（微信内置浏览器也能开，但麦克风权限可能受限，见下方说明）。

**建议**：戴耳机。她的声音、雨声、《特别的人》都在细节里。

---

## 六幕流程

| 幕 | 内容 | 背景音乐 |
|---|---|---|
| ① | 黑场，一滴水落下晕开 | 《特别的人》前奏（从 22 秒起） |
| ② | 雨夜，茉莉承接雨滴。**雨滴真实打在花瓣上会颤动、留下水珠滑落** | 《特别的人》继续 |
| ③ | 微信来电，两个头像，从"正在拨打"到"已接通" | **无音乐**（按你的要求） |
| ④ | 黑白灰红四色亮起，红色那块开始跳动 | 《特别的人》（从 40 秒起） |
| ⑤ | 信。全文逐段浮现，朱红印章落款 | 静音 |
| ⑥ | 蛋糕，吹蜡烛 | 吹灭后《特别的人》轻轻收尾 |

**操作**：轻触屏幕任意处进入下一幕。右下角有声音开关，底部有进度点（可直接跳）。

## 关于吹蜡烛

用的是**真实麦克风检测**。她会看到：

1. 屏幕提示「对着屏幕，轻轻吹一口气」
2. 她吹气时，下方波纹会随呼吸起伏，进度条累积
3. 持续约 1 秒 → 火焰熄灭，一缕青烟升起
4. 祝福词浮现：**秦源悦 / 十九岁生日快乐**

**如果麦克风不灵，有三重保险：**
- 轻吹也认（阈值调低了，安静环境轻声吹也能触发）
- 拒绝授权 / 设备不支持 → 自动切换成 5 秒动画吹灭
- 18 秒还没吹灭 → 提示「点一下火苗也可以」，**直接轻触火焰或蛋糕就能吹灭**

所以不会卡住。

> ⚠️ **如果她用微信内置浏览器打开**，麦克风权限可能被拦。这种情况会自动走 5 秒动画吹灭，不影响体验。想要真实吹气效果，建议让她用系统浏览器（Safari / Chrome）打开。

## 关于素材

**用的都是你给的东西，没有额外加工：**

- 信 —— **一字未改**，包括 🤓 🥰 🙃 💖 ❄️ 这些表情，和「瑞❄️」的落款
- 《特别的人》—— 你上传的版本，只做了淡入淡出
- 《好想爱这个世界啊》伴奏 —— 你上传的版本，压缩到 128k（音质无损，体积从 914KB 降到 366KB）
- 两张头像 —— 用在来电、信、蛋糕三个地方

**茉莉和雨**是用代码画的（Canvas），不是图片。每一滴雨落在花瓣上的位置、颤动幅度都是实时计算的，所以每次看都不一样。

## 音乐是怎么放的

两条音轨，按场景自动切换，你什么都不用管：

| 场景 | 放什么 |
|---|---|
| 开场点击后 → 茉莉雨 | 《特别的人》 |
| **来电幕** | **《好想爱这个世界啊》伴奏**（就是你的铃声） |
| 色彩 → 信 | 《特别的人》继续 |
| 蛋糕幕（吹蜡烛前） | 静音，专心许愿 |
| **吹灭蜡烛后** | 《特别的人》**从 0 开始循环**，一直放下去 |

**《特别的人》会单曲循环**——曲终自动从头再来，不会停。
右下角有个喇叭图标，可以随时静音。

> **关于"点了进入却听不到音乐"**：浏览器（尤其 iOS Safari 和 Chrome）
> 规定音频必须由用户手势触发。所以**第一次点击"进入"按钮时**才会真正放音，
> 这是正常的。页面已经做了预加载 —— 点进入的瞬间两首歌就开始缓冲，
> 到茉莉雨那一幕时《特别的人》从 22 秒处淡入，不会有明显的空白等待。
> 如果确实遇到没声音，先点一下右下角喇叭看看是不是误触静音了。

## 关于字体

除了**信纸正文**（保持原本的衬线感，读起来像手写信），其他所有文字都用了一套**更圆润的字体**——系统里能找到的圆体/幼圆优先，找不到就退回系统默认黑体。不会出现"太正经显得呆"的感觉。

蛋糕幕吹灭后的祝福词，排版是：

```
        秦源悦
    十九岁 生日快乐
    ─────────────
  愿你永远自由，无拘无束，为自己而活
        [ 再看一遍 ]
```

「十九」用红色放大，和「岁」「生日快乐」分开排，不会挤在一起。

## 技术说明

- 单文件 HTML + Canvas 动画，无外部依赖，离线可用
- 适配手机竖屏和电脑横屏
- 已测试：JS 语法、资源完整性、吹蜡烛流程（麦克风路径 + 降级路径）、信的分段渲染、音频切换链路（逐幕验证 readyState / volume / currentTime）

**已知限制**：《我好像在哪见过你》是腾讯独家版权曲，我无法取得，所以网页里没有它。信里提到了这首歌，但只是作为文字提及。
